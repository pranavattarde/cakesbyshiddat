# Cakes By Shiddat API

NestJS and Prisma API for the public website and administration panel.

Use the repository-level [README](../README.md) for installation, environment variables, database setup, and deployment instructions.

Common commands:

```bash
npm ci
npm run start:dev
npm run build
npx prisma validate
npx prisma migrate deploy
npm run seed
npm run start:prod
```
